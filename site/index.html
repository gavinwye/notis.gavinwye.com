Review a page by leaving a note on the exact words.

Select text and leave a note on it. The note stays attached to those words, and everyone who opens the page sees it.

Think comments in Google Docs, for any web page.

Try it on this page. Select any sentence here, then click the Add note button that appears.

On this page, notes are saved in your browser only. On your own site they're shared.

Why it exists

Feedback by email, in Slack or in a meeting isn't attached to anything. "The intro feels long" could mean one paragraph or the whole section, and with several reviewers the feedback overlaps, repeats itself or disagrees.

With Notis, the reviewer selects the words they mean and leaves a note on them. You get the words and the note together, in one list, without anyone needing an account.

It started as a way to get quick reactions to early prototypes, from people who had no time for a tool.

Notis is Swedish for a short note. Say it noh-tis.

How it works

  1. Select. A reviewer highlights text and leaves a note.
  2. Discuss. A side panel lists every note in page order. People reply, and resolve what's done.
  3. Fix. Open notes are plain JSON. You, a script or an AI assistant can read them, change the page, and mark them resolved.

Pin a note to an image

Some things you can't select. Open the panel, choose Pin on image, then click the spot you mean. The pin stays at that point, even when the image is resized.

Try it on the wireframe above. Pins are saved in your browser only.

See every note in one place

The dashboard lists every page that has notes: how many are open, how many are resolved, and how many are new since you last looked. Open a page to read its notes, reply, resolve them, or jump straight to the words they are about. Export what you are looking at as Markdown.

Try the dashboard. It uses invented notes, runs in your browser and saves nothing.

The dashboard is part of the server you already run, so there is nothing more to install. It is private by default and asks for your admin token. If your notes aren't private you can open it to anyone with one setting, COMMENTS_DASHBOARD=public.

Add it to a page

Copy one file into your site, then add one line before </body>. The file runs from your own server, so your visitors never contact this site.

<script src="/comments.js" defer></script>

The file is https://notis.gavinwye.com/v<version>/comments.js. The current version and its checksum are in version.json. A versioned address never changes, so a copy you check against that checksum is exactly what was released.

Notes are stored by a small server function on your own host: Netlify, Cloudflare Workers or Node. Set an admin token, and you're done. There's no database and nothing to build.

Setup, options and the API are in the README.

Just trying it? Load it from this site instead

This works anywhere you can add a tag, but every visitor's browser then fetches the file from notis.gavinwye.com, so your page depends on this site being up and this site sees each visit. I wouldn't use it in production.

<script src="https://notis.gavinwye.com/v<version>/comments.js"
  integrity="sha384-<hash from version.json>"
  crossorigin="anonymous" defer></script>

Or ask an agent to do it

Paste this into Claude Code, Codex, Cursor or any coding agent that's working in your site's folder:

Add Notis to this site. Follow the instructions at https://notis.gavinwye.com/install.md

The agent reads install.md, asks you where it should run, adds the script, and checks it works. It asks before it sets up shared storage.

Keep it up to date

Because the file lives on your own server, it only changes when you change it. Nothing about your site moves without you, and you choose when to update. When a new version comes out, replace the widget file and the server file together: a server update can be a security fix.

The quick way is the same one-line habit:

Update Notis in this site. Follow the instructions at https://notis.gavinwye.com/update.md

The agent compares your copy with the latest version, reads the changelog for what changed, replaces the files, keeps your settings, and checks your notes are still there. See update.md. To check by hand, type NotisVersion in the browser console and compare it with version.json, or watch the GitHub releases.

What you get

Anchored to text

Notes find their words again when the page loads, and survive small edits.

Replies

Replies, resolve and reopen, and a toggle for resolved ones.

A dashboard

Every page with notes in one list, with counts and a link to each note. Try it.

Take it with you

Copy a page's notes as Markdown or download them as JSON, from the panel or the dashboard.

No accounts

People type a name. You decide who can load the page.

One file, no dependencies

The widget injects its own styles. It works with any site, any framework.

What it doesn't do

  • No sign-in. Anyone who can load the page can leave a note. Put review copies behind a password or a preview URL.
  • No notifications. Nobody is emailed. You look at the panel or read the API.
  • Not for busy pages. It's built for a handful of reviewers, not a public comment section.
